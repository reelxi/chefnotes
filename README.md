# 👨‍🍳 ChefNotes – Recipe App Playground

This project started as a personal learning playground and a gift to my wife.
A recipe app to store her most delicious creations 🍲❤️

Along the way, it became a fullstack learning project with modern web technologies and Docker integration.

---

## 🛠 Tech Stack

- [**Ionic**](https://github.com/ionic-team/ionic-framework) – to bring the app to Android and iOS 📱 *(new to me)*
- [**Angular**](https://github.com/angular/angular) – for building the modern frontend web application 🌐
- [**NestJS**](https://github.com/nestjs/nest) – to structure the backend with best practices 🧠 *(new to me), (dockerized)*
- [**PostgreSQL**](https://github.com/postgres/postgres) – to store all the delicious recipes 🍽 *(dockerized)*
- [**Docker**](https://github.com/docker-library) – to containerize the entire app environment ⚙️

---

## 📦 Features (so far)

- Relational recipe model (Ingredients, Steps, Nutrition, etc.)
- Faker-based seeder (with real recipes like Spaghetti Bolognese)
- Dockerized setup for development and production
- Modular NestJS backend

---

## 🚧 Work in Progress

This project is still evolving.
I plan to add:

- Authentication (JWT)
- Swagger documentation
- Full CRUD support for all entities
- Mobile app with Ionic + Angular

---

## 🤓 Why I built this

> "Learning by doing" is powerful.
